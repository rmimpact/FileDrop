# FileDrop

A modern cross-platform file sharing application for macOS and Windows.

FileDrop lets you quickly send files between nearby devices over the same local network (Wi-Fi or Ethernet) without needing cloud storage, accounts, USB drives, or internet access.

---

## Features (Version 1)

- Discover nearby devices automatically
- Send files between:
  - macOS → macOS
  - Windows → Windows
  - macOS → Windows
  - Windows → macOS
- Drag and drop file sending
- Accept / Deny transfer requests
- Transfer progress bar
- Save received files directly to the Downloads folder
- Modern desktop interface built with Angular
- Native desktop application powered by Tauri and Rust

## Project Goal

Build a fast, lightweight, native-feeling alternative to AirDrop that works across both macOS and Windows.

The focus of Version 1 is simplicity:

1. Open FileDrop.
2. Select a nearby device.
3. Drag and drop a file.
4. The receiver accepts the transfer.
5. The file arrives.

No accounts. No cloud. No internet required.
