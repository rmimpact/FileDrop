# FileDrop

## Goal:
Send files between Mac and Windows over the same Wi-Fi.

**Version 1 Features:**
- See nearby devices
- Select one device
- Drag and drop one file
- Receiver gets Accept / Deny popup
- Show progress bar
- Save to Downloads

**Not Version 1:**
- Bluetooth
- Internet sending
- Login accounts
- Encryption
- Phone app
- Huge folder syncing
